# nib 0.12.1

Small fixes after 0.12.0.

- The empty-screen line now shows effort too: project · branch · model · effort. It is left out when the service picks the effort.
- `tools.llm` without `model` uses the service's small model at that model's default effort, so quick side calls are cheaper and faster.
- The README shows a nib vs Codex CLI chart: wall time, cost, requests and input tokens on the same model.

# nib 0.12.1（中文）

0.12.0 之后的小修。

- 空会话的那行信息现在也显示 effort：项目 · 分支 · 模型 · effort。由服务端决定 effort 时不显示。
- `tools.llm` 不指定 `model` 时，使用该服务的小模型，并采用该模型自己的默认 effort，旁路调用更便宜、更快。
- README 新增 nib 与 Codex CLI 的对比图：同一模型下的耗时、费用、请求数和输入 token。
