# nib 0.12.0

Quieter reading, clearer results, and fewer wasted Steps.

## Reading

- Tagged code blocks get light syntax marks: comments dim, strings in the terminal's cyan, keywords bold. Supported: zig, js/ts, python, shell, rust, go, c/c++. Other blocks stay plain.
- In diffs, a changed line paired with its replacement shows the changed words in bold.
- An empty screen shows one dim line: project · branch · model.

## Results

- After a successful Turn that edited files, one dim line under the footer says `3 files changed · +42 −7`; click it (or Ctrl+O) to list each file. Hidden in Simple mode.
- New `open` setting in config.toml, e.g. `open = "zed {path}:{line}"`: file paths in replies, the changes list and opened Runs become clickable and open in your editor. Unset, nothing changes.

## Input

- Ctrl+C quits only on a second consecutive press; the first shows `press ctrl+c again to quit`. Ctrl+D on an empty input still quits at once.
- Input prediction now sees your recent messages and matches their length and tone, answers the reply's closing question, and no longer shows "no reply needed"-style text. Short answers like "ok" are shown; thanks are not.

## Models

- When Run output exceeds the display budget, the omission marker names the missing lines (`[… bytes omitted · lines 120–480]`), so the model can re-read exactly what it missed.

## Tools

- `scripts/stats.py` reports the Step of the first edit, the re-read rate before it, and how often Run output is truncated.

# nib 0.12.0（中文）

阅读更安静，结果更清楚，浪费的 Step 更少。

## 阅读

- 带语言标记的代码块有了淡淡的语法标记：注释变暗，字符串用终端的青色，关键字加粗。支持 zig、js/ts、python、shell、rust、go、c/c++，其他代码块保持原样。
- diff 中一行改动与它的替换行成对时，变化的字词加粗显示。
- 空会话时显示一行淡色信息：项目 · 分支 · 模型。

## 结果

- 成功且改过文件的 Turn，在底部统计下方多一行淡色的 `3 files changed · +42 −7`；点击（或 Ctrl+O）展开每个文件。Simple 模式下不显示。
- config.toml 新增 `open` 设置，例如 `open = "zed {path}:{line}"`：回复里的文件路径、改动列表和展开的 Run 中的文件都可以点击，在编辑器中打开。不设置则一切照旧。

## 输入

- Ctrl+C 需要连续按两次才退出，第一次会提示 `press ctrl+c again to quit`。空输入时 Ctrl+D 仍然一次退出。
- 输入预判现在会参考你最近的消息，模仿它们的长短和语气；回复以问题结尾时直接预判你的回答；不再显示"无需回复"之类的文字。"好的"这类短回答会显示，"谢谢"不会。

## 模型

- Run 输出超出展示预算时，省略标记会写明缺失的行（`[… bytes omitted · lines 120–480]`），模型可以精确补读。

## 工具

- `scripts/stats.py` 新增统计：第一次编辑所在的 Step、编辑前的重读率，以及 Run 输出被截断的比例。
