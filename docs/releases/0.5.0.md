# nib 0.5.0

This release makes the TUI easier to read and control: stable Run blocks, clear background status, per-Turn file undo, and text selection across screens. UI summaries come entirely from local tools and events, without extra model calls or prompt requirements. Fixed interface text is English; model responses still follow your language.

## New commands and help

- **`/tasks`**: inspect background agents, bash, and automatically backgrounded Runs in the current Session, including id, status, duration, and deadline.
- **`/stop <id>`**: stop a task directly, including during execution. Stopping may leave partial changes and does not mean validation succeeded; executions replaced by new commands show superseded.
- **`/undo`**: revert the latest Turn's edit/write changes, including subagents, deleting newly created files. External changes cause rejection of the entire Turn's undo; bash, formatters, and script side effects are excluded. The current TUI instance retains the latest 8 edited Turns; undo does not survive exit or Session switching. Snapshot limits or save failures do not block editing, but make the Turn incompletely undoable and prevent skipping it to undo older Turns. See [undo scope and limits](https://github.com/yyydddkkk/nib-code/blob/v0.5.0/docs/undo.md).
- **`/status`**: inspect detailed timing, Step counts, and cache data; the Turn footer keeps concise statistics only.
- **`nib --help` / `-h`**: view usage without loading credentials; unknown options point to the correct help entry. TUI `/help` and menus group commands as Send / View / Session.

## Transcript interface

- Runs retain their parent block, showing actual calls, file changes, command exit codes, and subtask status; read/search paths appear once. Background results return to the original block; background registration gets no success checkmark.
- Ctrl+O expands Changes / Result / Script; results scroll, and long diffs explicitly state preview scope. Inspect final errors through Details.
- Activity shows waiting, generation, execution, or retry and cumulative Turn time, flagging prolonged lack of progress. Step numbers that do not help users act are removed. Failed-attempt drafts are cleared; queued messages not yet delivered return to input after cancellation or failure.
- User messages retain the `›` prefix, with a blue accent and subtle background adapted to terminal light/dark themes; body text uses the default terminal foreground. Long messages still collapse; queued messages retain their queued marker.
- Empty-screen guidance, paste previews, units, and shortcut wording are consistent, with concise layouts at 60 / 120 / 160 columns. See [UI style](https://github.com/yyydddkkk/nib-code/blob/v0.5.0/docs/ui-style.md) for details.

## Selection across screens

While dragging a mouse selection, hold the left button and scroll up or down to extend across screens. Selection anchors to historical entries and lines, pausing bottom following; release copies the whole range, including offscreen lines. User messages retain their blue accent when terminal color reports are unavailable. Copying keeps OSC 52 and existing local clipboard support; terminal settings still determine whether OSC 52 is allowed.
