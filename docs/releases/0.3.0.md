# nib 0.3.0

这一版的重点是让 Run 可以复现，并让工具和任务的并发行为变得可靠。nib 开始以 MIT 许可证开源。

## 破坏性变更

- **`tools.agent` 失败时不再 reject**：成功返回 `{ ok: true, id, text, usage, changes }`；超时、崩溃、非零退出时返回 `{ ok: false, id, error, text, usage, changes }`。只有参数错误和用户取消（Esc）仍会 reject。
- **Run 里一个调用失败，不再取消其他调用**：顶层 Promise reject 后，在途和排队的工具会继续执行完；Run 仍报告原始的拒绝原因。只有用户取消或 JS 执行超时才会中止它们，这时输出会多一行 `[stopped before completion: …]`。
- **每个 Turn 默认不再限制 Step 数**：原来写死上限 50。需要上限时，在 `config.toml` 的 `[limits]` 里设置 `max_steps`；设置后，system prompt 会写明这个上限，剩余 Step 不多于 3 个时，Run 输出会附上剩余数量。
- **bash 退出时清理整个进程组**：用 `nohup` 或 `&` 启动的进程，在命令返回后会被结束。需要长期运行的服务，改用 `tools.bash({ background: true, detached: true })`。
- **`write` 会拒绝过期覆盖**：如果文件在本会话上次读取后被外部修改过，写入会被拒绝；重新 `read` 后再写即可。

## 新功能

- **工具录制与离线重放**：工具调用的参数和结果默认录制到 `~/.nib/sessions/<id>.calls.jsonl`（权限 0600）。`nib replay <id> --run 1:0` 或 `--all` 会用录制的结果重跑 Run 的 JS，不请求模型，然后逐字节对比输出并报告第一次分歧；`--script` 可以用改写过的代码重跑。设置 `NIB_RECORD=off` 可关闭录制。见 [replay.md](../replay.md)。
- **后台任务**：
  - `tools.agent` 和 `tools.bash` 支持 `background: true`，调用立即返回任务 id，结果会在之后的 Step 里作为消息送达；
  - `detached: true` 的 bash 可以跨 Turn 存活，不阻塞最终回答，适合开发服务器；
  - `tools.stop({ id, reason })` 按 id 停止任务；reason 必须非空白，取消会提醒未完成验证没有通过结果。
- **子 agent 复用**：`tools.agent({ resume: "a1", prompt })` 在原来子会话的历史上继续工作，任务 id 保持不变。
- **子 agent 可以单独指定 `model` 和 `effort`**，返回结果里附带它改动过的文件（`changes`）。
- **统一的任务编号**：agent 编号为 `a1, a2…`，bash 编号为 `b1, b2…`，在整个会话内递增，恢复会话后接着编号。TUI 在 Run 下方用状态树显示子任务；超过 3 秒的前台 bash 也会出现在树里。
- **`tools.sleep(ms)`**：可取消的等待，可用于在 Run 内轮询。
- **主模型逐 Step 调度推理强度**：模型可以给下一个 Step 声明更低的 effort。用户设置的值是上限，Run 失败或用户插话后自动恢复。
- **TUI**：
  - 回合进行中可以插话，插入的消息会排队续发；
  - 每轮结束时显示账单：推理与工具耗时、token 用量、缓存命中，以及工具数据量和最终进入上下文的字节数（`工具字节→输出字节 B`）。
- **`config.toml` 新增 `[limits]` 段**：可以配置 `tools.llm` 和子 agent 的并发与配额、`max_steps`，以及 `stream_idle_timeout_s`。见 [config.md](../config.md#limits)。
- **实验标签与分组统计**：会话日志会记录 system prompt 的版本和启用的补丁，`scripts/stats.py --group-by` 可以按这些维度对比往返次数和耗时。用 `NIB_PATCHES_OFF` 可以关闭指定的提示补丁。

## 改进与修复

- 文件安全：
  - `edit` 和 `write` 先写同目录下的临时文件，再用 rename 原子替换；
  - 多个 nib 进程通过 `~/.nib/locks/` 下的锁协调对同一文件的读写，包括子会话之间。
- 模型的流式响应超过 300 秒（可配置）没有收到数据时，按连接中断处理并重试，不会无限挂起。
- 如果 bash 的后台子进程继承了 stdout，`tools.bash` 不再等这些子进程结束才返回。
- 后台任务内部出错只上报一次；后台结果的字节数计入接收它的那个 Step。
- Run 的改动统计按每次 edit/write 累加，不会把其他进程同时做的改动算到当前 Run 上。
- TUI 中，已结束 Run 的工具摘要改为按实际发生的调用统计。
- 使用 heredoc 时，正文不再占用 bash 安全检查的词数预算。
- `tools.grep` 支持传入 RegExp 字面量。
- 内部重构：把 `session`、`sandbox`、`tui` 和 `transcript` 拆成按职责划分的小模块，行为不变。
