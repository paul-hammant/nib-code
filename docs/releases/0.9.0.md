# nib 0.9.0

Quieter screen, two ways to extend, and one command to upgrade.

## Upgrade

- `nib update` upgrades in place: it verifies `SHA256SUMS` and atomically replaces the binary. `nib update 0.9.0` pins or rolls back. Nothing checks for updates on its own.

## A quieter screen

- The key-hint line under the input is gone; one blank row keeps the input off the bottom edge.
- Hovering a Run, background result, or failure shades the whole block; click its summary to open it. Text inside opened details stays selectable.
- Hints for well-known keys are removed: `Esc to cancel`, `PgDn to return`, `Details (click)`, `Enter saves`, `Esc cancels`. `No provider · /provider to sign in` stays.
- The Add endpoint protocol step is a menu instead of a typed number.

## MCP

- Add servers under `[mcp.<id>]` in `config.toml`, as a command or a URL. Every server is off until `/mcp on <id>`.
- Enabled servers add one line per tool to the prompt; `tools.mcp_schema` returns full schemas on demand. Disabled servers add nothing.
- The model calls `tools.mcp("server.tool", args)` inside Runs. Tool lists are cached until the server reports a change.
- Speaks MCP 2026-07-28 and falls back to older servers. Tools only for now.

## Hooks

- `[hooks] after_edit = ["zig fmt {files}"]` runs once after a Run that changed files. Success is silent; a failure goes to the model with its exit code and output, and the Run shows `hook … · exit 1`.
- `[hooks] turn_end = [...]` runs when a Turn ends, for notifications. Its output is discarded.

## Sandbox is now opt-in

- By default nib runs with your permissions, like you would. Where "dangerous" begins cannot be drawn well: editing `~/.zshrc` or writing to `.git/hooks` is sometimes an attack and sometimes the task.
- `[sandbox] mode = "workspace"` keeps the 0.8.0 behavior: writes only to the project, temp dirs, and build caches. Executable directories such as `~/.cargo/bin` are no longer writable in that mode.
- bash still refuses obviously destructive commands, and nib's credential file stays off limits.

## Other

- `/reflect` appears only when `NIB_ISSUE_REPO=owner/name` is set; it no longer files issues to this repository by default.

# nib 0.9.0（中文）

界面更安静，多了两种扩展方式，升级只需一条命令。

## 升级

- `nib update` 原地升级：校验 `SHA256SUMS` 后原子替换二进制。`nib update 0.9.0` 可指定版本或回退。nib 不会自行检查更新。

## 更安静的界面

- 去掉输入框下方的按键提示行，输入框下留一行空白，不贴底。
- 鼠标移到 Run、后台结果或失败条目上，整块会出现淡淡的底色；点击摘要即可展开。展开后的详情仍可正常选中文字。
- 去掉众所周知按键的提示：`Esc to cancel`、`PgDn to return`、`Details (click)`、`Enter saves`、`Esc cancels`。`No provider · /provider to sign in` 保留。
- 添加站点时选择协议改为菜单，不再输入数字。

## MCP

- 在 `config.toml` 的 `[mcp.<id>]` 中添加服务器，可以是命令或 URL。所有服务器默认关闭，用 `/mcp on <id>` 开启。
- 开启的服务器每个工具只占提示词一行；需要完整参数时，模型用 `tools.mcp_schema` 获取。未开启的服务器不占任何上下文。
- 模型在 Run 中调用 `tools.mcp("server.tool", args)`。工具列表会缓存，服务器通知变化时才重新获取。
- 支持 MCP 2026-07-28，并兼容旧版服务器。目前只支持工具调用。

## Hooks

- `[hooks] after_edit = ["zig fmt {files}"]`：Run 修改文件后执行一次。成功时不显示；失败时把退出码和输出交给模型，Run 中显示 `hook … · exit 1`。
- `[hooks] turn_end = [...]`：每轮结束时执行，适合发通知。输出直接丢弃。

## 沙箱改为可选

- 默认以你的权限运行，就像你自己操作一样。"危险操作"的边界很难划清：修改 `~/.zshrc`、写 `.git/hooks`，有时是攻击，有时恰恰就是任务本身。
- `[sandbox] mode = "workspace"` 保留 0.8.0 的行为：只能写项目、临时目录和构建缓存。该模式下 `~/.cargo/bin` 这类可执行目录不再可写。
- bash 依然拒绝明显的破坏性命令，nib 的凭证文件依然禁止访问。

## 其他

- `/reflect` 只在设置了 `NIB_ISSUE_REPO=owner/name` 时出现，默认不再向本仓库提交 issue。
