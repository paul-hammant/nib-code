# nib 0.2.0

## 破坏性变更

- **用户目录统一为 `NIB_HOME`（默认 `~/.nib`）**：全局 `AGENTS.md`、`sessions/` 和 `config.toml` 都放在这个目录下。nib 不再读取 XDG 路径，也不会自动迁移旧文件。从 0.1.0 升级时，需要手动移动旧文件：

  ```bash
  mkdir -p ~/.nib
  mv ~/.local/share/nib/sessions ~/.nib/
  mv ~/.config/nib/AGENTS.md ~/.nib/   # 如果有
  ```

- **`tools.grep` 的结果字段变了**：长行会围绕命中位置截取，并新增 `column` 字段，表示命中位置在行内的字节列（从 1 开始）。
- **`tools.read` 的返回值改为 `{ text, next_offset }`**：返回内容不再做中间截断。

## 新功能

- `tools.llm`：在 Run 里异步、可并发地发起一次干净的模型推理，适合批量判断、分类、抽取，支持传入 schema 得到结构化结果。默认限额：并发 4 个，每个 Run 最多 100 次，单次输入最多 256 KiB。见 [tool-delegation.md](../tool-delegation.md)。
- `config.toml`：可以持久化 provider、model、effort 的设置；在 TUI 里执行 `/effort` 会自动保存。
- `/reflect`：模型对照会话日志复盘 harness 遇到的阻碍，结果追加到 `reflections.md`，并自动发布 GitHub issue。发布前会先查重、脱敏。见 [reflect.md](../reflect.md)。
- 输入框改版：
  - 圆角边框，上方有活动行，下边框显示元数据；
  - 粘贴超过 5 行时折叠成 `[Pasted #N]` 块；
  - 长消息默认折叠显示。
- 子 agent 运行时显示进度：折叠时是一行汇总，按 ctrl+o 展开可看到每个子任务。
- 鼠标选中文本即可复制，同时支持 OSC 52 和本地剪贴板。
- 分段计时：会话日志记录每个 Step 的模型耗时、参数到达进度和工具调用耗时；`scripts/stats.py` 增加耗时构成，`--since` 改为按记录时间筛选。

## 改进与修复

- Codex：
  - 按会话设置 prompt cache key，缓存命中正常了；
  - 流中途失败时保留服务端给出的原因，临时错误和限流会自动重试；
  - 请求推理摘要，活动行显示静默时长。
- Run 输出按 console 调用和最终结果分条截断，并标明省略了多少字节；console 的末尾内容会保留下来。
- Run 的超时只计算 JS 执行时间，不包括等待工具的时间；子 agent 默认超时改为 30 分钟。
- 按 Esc 能立即中断卡住的模型请求；中断时会保留用户消息和已经输出的文本。
- 对话区不再显示推理内容，活动行仍然显示 thinking 阶段。
- 精简了系统提示和工具说明，项目 AGENTS.md 也大幅缩短，细节挪到 `docs/`。
