# nib 0.10.1

Simple mode, corrected; resizing fixed.

## Simple mode

- Uses the same width and spacing as normal mode; the centered column and the extra space between turns are gone.
- Keeps the normal input box, without the placeholder text.
- The input box's bottom border carries no model name or context meter. Above 80% context, a dim ` context N% ` appears on its right.
- Turn footers stay hidden and Runs stay one line, as in 0.10.0.

## Resizing

- nib now follows terminal resizes. Before, after enlarging a window it could keep drawing at the old size, which left misaligned glyphs, most visibly when switching modes afterwards.

# nib 0.10.1（中文）

修正 Simple 模式，修复窗口缩放。

## Simple 模式

- 宽度和间距与普通模式一致，去掉了居中栏和每轮之间多出的空白。
- 保留普通模式的输入框，只去掉占位文字。
- 输入框底边不显示模型名和上下文用量；上下文超过 80% 时，右侧出现淡色的 ` context N% `。
- 与 0.10.0 相同，每轮统计依然隐藏，Run 依然收成一行。

## 窗口缩放

- nib 现在会跟随终端尺寸变化。此前放大窗口后可能仍按旧尺寸绘制，导致符号错位，切换模式后尤其明显。
