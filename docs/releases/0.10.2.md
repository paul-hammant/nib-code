# nib 0.10.2

More room to read: steadier input, clearer typography, real tables.

## Layout

- The input box sits on the last row of the terminal.
- One row above it is reserved for status: the spinner and phase while working, blank when idle. The input box no longer moves when status appears.
- Sent messages show only the blue bar, without `›`; `›` now belongs to the input.
- The bottom border leaves a space after the model name. In Simple mode, the ` context N% ` label moves to the input box's top border.

## Typography

- Paragraphs are separated by a blank line, even when the model breaks lines with a single newline.
- Headings get a blank line above them.
- Inline code and code blocks drop the yellow: normal text on a faint background tint, without a language label.
- Italic text is italic; links show their text followed by the dim URL; quotes get a dim bar.
- Run titles are normal brightness; the lines below them stay dim.
- Color has one accent, blue, for the message bar, headings, and the input prompt. Red, green, and yellow mean state only.

## Tables

- Markdown tables are drawn without pipes: a bold header, one dim rule, and columns aligned by display width (CJK counts as two). `:---:` and `---:` center or right-align a column. Tables wider than the terminal stay as written.

# nib 0.10.2（中文）

读起来更舒展：输入框更稳，排版更清楚，表格真正对齐。

## 布局

- 输入框贴住终端最后一行。
- 输入框上方固定留一行显示状态：运行时显示转圈和阶段，空闲时空白。状态出现或消失时，输入框不再跳动。
- 已发送的消息只保留蓝色色条，不再显示 `›`；`›` 只属于输入框。
- 底边的模型名后面留一个空格。Simple 模式下，` context N% ` 移到输入框的上边框。

## 排版

- 段落之间空一行，即使模型只用单个换行分段。
- 标题上方空一行。
- 行内代码和代码块去掉黄色：正常文字加淡底色，不标注语言。
- 斜体显示为斜体；链接显示文字，后跟淡色网址；引用左侧加淡色竖线。
- Run 标题用正常亮度，下面的明细保持淡色。
- 颜色只有一个强调色：蓝色，用于消息色条、标题和输入提示符。红、绿、黄只表示状态。

## 表格

- Markdown 表格不再显示竖线：表头加粗，下面一条淡色细线，各列按显示宽度对齐（中文算两格）。`:---:` 和 `---:` 让该列居中或右对齐。超过终端宽度的表格保持原样。
