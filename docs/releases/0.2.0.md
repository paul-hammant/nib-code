# nib 0.2.0

## Breaking changes

- **Unified user directory `NIB_HOME` (default `~/.nib`)**: global `AGENTS.md`, `sessions/`, and `config.toml` live here. nib no longer reads XDG paths or migrates old files automatically. Upgrading from 0.1.0 requires moving files manually:

  ```bash
  mkdir -p ~/.nib
  mv ~/.local/share/nib/sessions ~/.nib/
  mv ~/.config/nib/AGENTS.md ~/.nib/   # if present
  ```

- **Changed `tools.grep` result fields**: long lines are excerpted around matches; the new `column` field gives the match's 1-based byte column within the line.
- **`tools.read` now returns `{ text, next_offset }`**: returned content is no longer truncated in the middle.

## New features

- `tools.llm`: asynchronous, concurrent, clean single model inferences within a Run for batch judgments, classification, and extraction, with schema-based structured results. Default limits: concurrency 4, 100 calls per Run, 256 KiB input per call. See [tool-delegation.md](../tool-delegation.md).
- `config.toml`: persist provider, model, and effort settings; TUI `/effort` saves automatically.
- `/reflect`: the model reviews harness obstacles against Session logs, appends results to `reflections.md`, and automatically publishes GitHub issues after duplicate checks and redaction. See [reflect.md](../reflect.md).
- Redesigned input:
  - Rounded border, activity line above, metadata in the bottom border;
  - Pastes over 5 lines collapse into `[Pasted #N]` blocks;
  - Long messages collapse by default.
- Live subagent progress: one summary line when collapsed; ctrl+o expands individual tasks.
- Copy text by selecting it with the mouse, with OSC 52 and local clipboard support.
- Segmented timing: Session logs record model time, argument-arrival progress, and tool-call time per Step; `scripts/stats.py` adds time breakdowns and `--since` filters by record time.

## Improvements and fixes

- Codex:
  - Per-Session prompt cache keys restore cache hits;
  - Midstream failures preserve server-provided reasons; transient errors and rate limits retry automatically;
  - Request reasoning summaries; show silent duration in the activity line.
- Run output truncates console calls and final results separately, indicating omitted bytes; console tails are preserved.
- Run timeouts count only JS execution, excluding tool waits; subagent default timeout is now 30 minutes.
- Esc immediately interrupts stuck model requests, preserving user messages and already emitted text.
- Reasoning is hidden from the transcript; the activity line still shows the thinking phase.
- Simplified system prompt and tool descriptions; project AGENTS.md is much shorter, with details moved to `docs/`.
