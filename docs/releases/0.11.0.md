# nib 0.11.0

Web search, input prediction, and `$skill` mentions.

## Web search

- New `tools.search({ query, count })` searches the web with the current service's credentials: ChatGPT sign-in and OpenAI (hosted search on `gpt-6-luna`), Anthropic (Claude Haiku with server-side search), and DeepSeek (its Search API, billed per request). No new keys or settings.
- Results come back as `{ ok, answer?, results: [{ title, url, date?, summary }] }`; read a page with `tools.fetch`. An answer produced without an actual search is reported as a failure, not as results.
- Services without search (xAI, custom endpoints) do not show the tool to the model.

## Input prediction

- After a Turn, nib predicts your next message in the background with the service's small model and shows it as dim text in the empty input. Tab accepts it; Enter sends.
- Typing hides it and clearing the input brings it back. It never blocks typing or sending, shows no progress, and failures stay silent. Prediction requests stay out of the Session: no log, no usage, no context.

## `$skill` mentions

- Write `$name` anywhere in a message to use that skill for this message only, without enabling it. Typing `$` opens a completion menu of discovered skills.
- Only exact skill names count; `$HOME` and other text stay as written. Skills marked `disable-model-invocation` can be mentioned too. Resumed Sessions keep what the model saw.

## Simple mode

- A collapsed Run shows what it touched on its one line, such as `Run · glob **/*.md` or `Run · read src/a.zig · edit 1 file`.

# nib 0.11.0（中文）

网络搜索、输入预判和 `$skill` 点名。

## 网络搜索

- 新增 `tools.search({ query, count })`，用当前服务的凭证搜索网络：ChatGPT 登录和 OpenAI（`gpt-6-luna` 的服务端搜索）、Anthropic（Claude Haiku 加服务端搜索）、DeepSeek（其搜索 API，按次计费）。不需要新的 key 或设置。
- 返回 `{ ok, answer?, results: [{ title, url, date?, summary }] }`；读取具体页面用 `tools.fetch`。没有真正搜索就给出的回答按失败处理，不当作搜索结果。
- 不支持搜索的服务（xAI、自定义端点）不会向模型展示这个工具。

## 输入预判

- 每轮结束后，nib 在后台用该服务的小模型预判你的下一句话，以淡色文字显示在空输入框里。按 Tab 接受，按回车发送。
- 打字时隐藏，清空输入框后重新出现。它不会阻塞输入或发送，不显示进度，失败也不提示。预判请求不进入会话：不写日志，不计用量，不占上下文。

## `$skill` 点名

- 在消息任意位置写 `$名字`，即可只对这一条消息使用该 skill，无需开启。输入 `$` 会弹出已发现 skill 的补全菜单。
- 只有完全匹配的 skill 名才算点名；`$HOME` 等文字保持原样。标记了 `disable-model-invocation` 的 skill 也可以点名。恢复会话时保留模型当时看到的内容。

## Simple 模式

- 收起的 Run 在一行里显示具体操作，例如 `Run · glob **/*.md`、`Run · read src/a.zig · edit 1 file`。
