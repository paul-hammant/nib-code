# nib 0.11.1

A completion fix and internal cleanup.

## Completion

- Moving the cursor straight from an `@` file mention to a `$` skill mention (or back) now lists the right candidates. Before, the menu could stay empty or show the previous list.

## Internals

- `/provider` sign-in keeps its state transitions, background jobs and model list inside one module.
- `/model` and `/provider` switch through one Session operation. If an in-place switch fails partway, the configuration is rolled back and nib reports `could not update session`.
- No other user-visible changes.

# nib 0.11.1（中文）

补全修复与内部整理。

## 补全

- 光标从 `@` 文件补全直接移到 `$` skill 补全（或反过来）时，菜单会列出正确的候选。此前菜单可能为空，或显示上一次的列表。

## 内部

- `/provider` 登录的状态转换、后台任务和模型列表集中在一个模块里管理。
- `/model` 和 `/provider` 通过同一个 Session 操作切换。原地切换中途失败时，配置会回滚，并提示 `could not update session`。
- 没有其他用户可见的变化。
