# nib 0.10.3

## Tables

- The rule under the header is gone, and the header is dim instead of bold. The data reads first; the only lines on screen are the input box's.

## Pasting images

- Many terminals handle Ctrl+V themselves and send an empty paste when the clipboard holds only an image. nib now reads the clipboard image on an empty paste and attaches it as `[Image #N]`; with no image it says `No image in clipboard` instead of doing nothing.
- Reading the clipboard gives up after 2 seconds, so a stuck clipboard tool cannot freeze the screen.

# nib 0.10.3（中文）

## 表格

- 去掉表头下的横线，表头改为淡色、不加粗。先读到数据，屏幕上的线条只剩输入框的边框。

## 粘贴图片

- 很多终端会自己处理 Ctrl+V，剪贴板里只有图片时只发来一个空粘贴。现在 nib 收到空粘贴时会读取剪贴板里的图片，附为 `[Image #N]`；没有图片时提示 `No image in clipboard`，不再毫无反应。
- 读取剪贴板最多等 2 秒，剪贴板工具卡住也不会冻住界面。
