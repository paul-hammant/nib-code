# nib 0.10.0

Simple mode: just the conversation.

## Simple mode

- `/simple` or Ctrl+S (Ctrl+Shift+S where the terminal tells them apart) switches to a reading layout; the choice is remembered.
- Turn footers, the model name, and the context meter disappear; `/status` keeps every detail. Above 80% context, a dim `context N%` appears on the input rule.
- The input box becomes a thin rule and a `›`, with no placeholder and one blank row below.
- Runs collapse to one line. Successful Runs carry no mark; failures and warnings keep `✗` and `!`. Click a Run to open it in full.
- On wide terminals the conversation sits in a centered column of about 100 characters, with a little more space between turns.
- Normal mode is unchanged and remains the default.

## Hover

- The highlight on hoverable blocks is now clearly visible, and falls back to the terminal's light or dark scheme when it does not report its background color.

# nib 0.10.0（中文）

Simple 模式：只留下对话。

## Simple 模式

- `/simple` 或 Ctrl+S（终端能区分时 Ctrl+Shift+S 也可以）切换到阅读布局，选择会被记住。
- 隐藏每轮统计、模型名和上下文用量；所有细节仍可在 `/status` 查看。上下文超过 80% 时，输入线上会出现淡色的 `context N%`。
- 输入框变成一条细线和 `›`，没有占位文字，下方留一行空白。
- Run 收成一行。成功的 Run 不加标记，失败和警告保留 `✗` 和 `!`。点击 Run 可展开完整内容。
- 终端较宽时，对话居中显示，宽约 100 个字符，每轮之间多留一点空白。
- 普通模式保持不变，仍是默认模式。

## 悬停

- 可悬停块的高亮现在清晰可见；终端不报告背景色时，按终端的深浅主题兜底。
