# nib 0.6.0

这一版让 nib 不再只连 Codex：内置 Claude、OpenAI、DeepSeek、Grok，也能接你自己的 OpenAI 兼容站点，用 `/model` 一步切换。skill 现在可以用了，但默认全部关闭，只有你打开的才会进入模型的上下文。

## `/model`

- 一个指令切换服务和模型。列表只显示当前能用的：Codex 已登录，或者对应的 API key 已设置。输入可过滤，也可以直接写 `/model anthropic` 或 `/model anthropic claude-opus-5-5`。
- 选择会保存到 `~/.nib/config.toml`，下次启动沿用。当前会话还没有对话时原地切换；已有对话则自动开新会话，旧会话仍可用原服务恢复。

## Provider

- 内置 `codex`（默认，行为不变）、`openai`、`anthropic`、`deepseek`、`xai`。线路协议只有三种：Responses、Chat Completions、Anthropic Messages；新增同协议的服务只加一行表项。
- 自定义站点写在 `[providers.<id>]`：`protocol`、`base_url`、`model`、`context_window`、`api_key_env`。配置里只存环境变量名，不存密钥。
- Claude 使用提示缓存断点和带签名的推理延续；密钥只交给 nib 自己的子 agent，模型运行的 bash 拿不到。
- 旧配置 `provider = "chat_completions"` 和旧会话日志照常可用。详见 [Providers](https://github.com/yyydddkkk/nib-code/blob/v0.6.0/docs/providers.md)。

## Skills

- 支持 Agent Skills 格式（`<dir>/<name>/SKILL.md`），扫描 `~/.agents/skills`、`~/.nib/skills`、项目内 `.agents/skills` 和 `.nib/skills`。
- **默认全部关闭。** 用 `/skills` 查看，`/skills on <name>` 打开，从新会话起生效。没有打开任何 skill 时，system prompt 与之前逐字节相同。
- 模型只看到名字、一句描述和路径，需要时自己读全文，不加新工具。详见 [Skills](https://github.com/yyydddkkk/nib-code/blob/v0.6.0/docs/skills.md)。

## 界面

- 流式输出按约 16 ms 合并刷新，长回复更顺滑；按键、滚动、取消仍立即响应，空闲时不重绘。
- 活动行和对话之间留一行空白，小窗口自动收紧。

## 安装与数据

- 预编译二进制与一行安装：`curl -fsSL https://raw.githubusercontent.com/yyydddkkk/nib-code/main/install.sh | sh`。
- README 增加与 Codex CLI 同模型的对比和资源占用数据，完整数据见 [benchmarks](https://github.com/yyydddkkk/nib-code/blob/v0.6.0/docs/benchmarks.md)。
