# nib 0.13.0

The first step toward tuning nib per model.

## Models

- nib now recognizes the model family from the model name (Codex/GPT, DeepSeek, Claude, or default), including custom endpoints such as one serving `deepseek-flash`. Session logs record it. Behavior is unchanged for now; later releases use it for model-specific tuning ([ADR 0025](../adr/0025-model-profiles.md)).
- The model can no longer lower reasoning effort for its next Step. Switching effort emptied the prompt cache on both Codex and DeepSeek, so it cost more than it saved. Your own setting (`/effort`, `--effort`, `effort` in config.toml) works as before, and old sessions still resume.

## Tools

- A bash command now returns as soon as its shell exits, even when it started a service that keeps the output open, such as `service … restart`. Such commands used to hang until the Turn timed out. The service keeps running.

## Stats

- `scripts/stats.py` explains uncached input: what was new content, what was lost at a Turn start, and what was lost mid-Turn, by cause (effort change, background result, interjection, compaction). `--group-by profile` groups by model family.

# nib 0.13.0（中文）

按模型调优 nib 的第一步。

## 模型

- nib 现在会根据模型名识别模型家族（Codex/GPT、DeepSeek、Claude 或默认），自定义服务也一样，比如提供 `deepseek-flash` 的自定义端点。会话日志会记录识别结果。目前行为不变，之后的版本会用它做针对模型的调优（[ADR 0025](../adr/0025-model-profiles.md)）。
- 模型不再能为下一步调低推理 effort。在 Codex 和 DeepSeek 上，切换 effort 都会让提示词缓存清零，得不偿失。你自己设置的 effort（`/effort`、`--effort`、config.toml 里的 `effort`）照常生效，旧会话也能正常恢复。

## 工具

- bash 命令在 shell 退出后立即返回，即使它启动的服务一直占着输出，比如 `service … restart`。以前这类命令会一直卡到这一轮超时。服务会继续运行。

## 统计

- `scripts/stats.py` 会拆解未命中缓存的输入：哪些是本来就新的内容，哪些在新一轮开始时丢失，哪些在一轮中间丢失，并按原因归类（切换 effort、后台结果、中途插话、压缩）。`--group-by profile` 可以按模型家族分组。
