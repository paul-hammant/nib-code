# nib 0.5.0

这一版让 TUI 更容易读懂和控制：稳定的 Run 块、清楚的后台状态、按 Turn 撤销文件修改，以及跨屏文本选择。界面摘要全部来自本地工具和事件，不增加模型调用或提示词要求；固定界面文字统一英文，模型回复仍跟随你的语言。

## 新指令与帮助

- **`/tasks`**：查看当前 Session 的后台 agent、bash 和自动转后台 Run，包含编号、状态、耗时与截止时间。
- **`/stop <id>`**：直接停止指定任务，运行中也可使用。停止可能留下部分修改，不等于验证成功；被新命令取代的执行显示 superseded。
- **`/undo`**：撤销最近一轮通过 edit/write 产生的修改，包含子 agent，新建文件则删除。外部修改会使整轮撤销被拒绝；bash、格式化器和脚本副作用不在范围内。当前 TUI 实例保留最近 8 个有修改的 Turn；退出或切换会话后不保留撤销能力。快照超限或保存失败不会阻止编辑，但该轮不可完整撤销，也不能跨过它撤销更早的轮次。详见 [撤销范围与限制](https://github.com/yyydddkkk/nib-code/blob/v0.5.0/docs/undo.md)。
- **`/status`**：查看详细计时、步数和缓存；轮末页脚只保留简洁统计。
- **`nib --help` / `-h`**：无需加载凭证即可查看用法；未知选项提示正确的帮助入口。TUI `/help` 与菜单按 Send / View / Session 分组。

## 文稿式界面

- Run 始终保留父块，展示实际调用、文件改动、命令退出码与子任务状态；读取/搜索路径只显示一次。后台结果回到原块，后台登记不显示成功勾号。
- Ctrl+O 按 Changes / Result / Script 展开；结果可滚动查看，长 diff 明确标注 preview 范围。最终错误可通过 Details 检查。
- 活动行显示等待、生成、运行或重试及整轮累计时间，长时间无进展会提示；移除无助于操作的 Step 编号。失败尝试的草稿会清理，取消或失败后尚未送达的排队消息返回输入框。
- 用户消息保留 `›` 前缀，配蓝色强调条与适配终端明暗主题的淡底色；正文使用终端默认文字色。长消息仍可折叠，排队消息保留 queued 标记。
- 空屏引导、粘贴预览、单位与快捷键文案统一，60 / 120 / 160 列保持简洁布局。详细规则见 [UI style](https://github.com/yyydddkkk/nib-code/blob/v0.5.0/docs/ui-style.md)。

## 跨屏选择

鼠标拖选时按住左键滚动滚轮，可向上或向下跨屏扩展选区。选区锚定到历史条目和行，选择期间暂停底部跟随；松开即复制完整范围，包括已经滚出屏幕的行。终端颜色报告不可用时仍保留用户消息的蓝色强调条。复制沿用 OSC 52 和已有的本地剪贴板支持，终端是否允许 OSC 52 仍由终端设置决定。
