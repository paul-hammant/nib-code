# nib 0.4.0

This release reduces waits in long commands and model requests for everyday development; defaults match the validated v7 configuration.

## Default behavior changes

- **Codex defaults to WebSocket**: reuse the connection within a Session, sending only new input when prefix conditions hold; handshake or protocol failures automatically fall back to SSE for the Session. Set `NIB_CODEX_TRANSPORT=sse` to force the old transport.
- **Codex defaults to custom Run**: the model generates JavaScript directly, reducing JSON string escaping. Set `NIB_CODEX_RUN_TOOL=function` to fall back; historical calls retain their original type, without conversion on resume.
- **Readable reasoning summaries default to off**: reasoning effort and encrypted reasoning continuation are unchanged; set `NIB_REASONING_SUMMARY=auto` to display summaries.
- **Ordinary bash defaults to a 30-minute timeout**: the same for foreground and explicit background calls; automatic backgrounding does not reset deadlines. Set `timeout_ms` explicitly if needed. Detached bash still defaults to no deadline and cleans up its process group on stop, cancellation, or exit.

These three Codex switches also work in `$NIB_HOME/config.toml`'s `[codex]` section, with environment variables taking precedence. See [configuration](https://github.com/yyydddkkk/nib-code/blob/v0.4.0/docs/config.md) and [Codex](https://github.com/yyydddkkk/nib-code/blob/v0.4.0/docs/codex.md).

## Long tasks and validation

- **Long Runs automatically move to the background**: after waiting for tools for over 10 seconds by default, the model receives a task notification while the original script and await continue; final output arrives automatically. Without independent work, Session waits locally rather than repeatedly requesting the model; adjust the threshold with `[limits].run_background_after_ms`.
- **Rerun validation directly after changes**: after edit/write changes within the same Session, rerunning identical command/cwd stops the same active bash from an earlier Run. The old call returns `{superseded_by:"bN"}`, indicating neither pass nor failure; scripts should handle this marker before inspecting exit codes. Detached calls, parallel calls within the same Run, and repetitions without changes are unaffected. Existing side effects are not rolled back.
- **Explicit stops require reasons**: `tools.stop({id, reason})` requires nonblank reason; stopping unfinished tests does not mean validation passed.
- **Delegation guidance reduces serial waits**: the main loop edits, builds, and tests by default; use independent investigation, fork, or resume after completion as tasks require.

Background Runs share files with other work, without workspace isolation; supersession stops only matching bash, and the original script can continue producing side effects. See [Run lifecycle](https://github.com/yyydddkkk/nib-code/blob/v0.4.0/docs/run-output.md#长-run-自动转后台) and [supersession semantics](https://github.com/yyydddkkk/nib-code/blob/v0.4.0/docs/tool-delegation.md#同一命令取代过时执行).

## Output, diagnostics, and compatibility

- Configure Run display budgets with `[limits].run_output_bytes` / `NIB_RUN_OUTPUT_BYTES`, still defaulting to 16 KiB; tools deliver complete data to JS, and console capture remains limited to 64 KiB. Offline replay uses the recorded budget.
- Model requests separately limit byte idle time (300 seconds), content idle time (120 seconds), and total attempt time (300 seconds), all configurable. Each retry resets timing, so the whole Step can take longer. Legitimate long reasoning may require higher limits.
- Logs preserve ordered Responses output, per-request diagnostics, transport fallback reasons, actual background execution intervals, and bash start/supersession events, distinguishing model waits from tool execution.
- Fixed Session resume and offline replay after transport fallback or missing previous response: independent diagnostics no longer count as history replacements.
- Old Sessions retain their original system; custom/function history and old recordings remain resumable/replayable. New script-error diagnostics may change old replay displays; old binaries are not guaranteed to read new logs. Check full commands and calls sidecars for sensitive content before sharing logs.

## Fallback configuration example

```sh
NIB_CODEX_TRANSPORT=sse NIB_CODEX_RUN_TOOL=function NIB_REASONING_SUMMARY=auto nib
```

These switches affect subsequent requests without rewriting history. ReleaseFast builds still use `zig build -Doptimize=ReleaseFast`.
