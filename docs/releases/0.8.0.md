# nib 0.8.0

Sign in from inside nib, show it a screenshot, point at a file, and let it work inside a sandbox.

## Sign-in and providers

- `/provider` lists every service with its status. Pick one to sign in: paste an API key (masked), or sign in to Codex with ChatGPT in the browser, with a device code over SSH. An existing Codex CLI login is used as is.
- `Add endpoint…` adds your own OpenAI-compatible, Responses, or Anthropic Messages service in four steps and lists its models; no config file editing.
- `/model` now lists only the current service's models.
- Keys live in `~/.nib/auth.json` (0600), are never shown, and are refused to file tools and bash. Environment variables still take precedence.
- A fresh install without credentials says `Not signed in`; sending a message opens `/provider` and keeps the draft.
- `nib login [service] [--device]` and `nib logout <service>` for the terminal.

## Images

- Paste or drop an image path, or press Ctrl+V, to attach a screenshot. It shows as `[Image #1]`.
- `tools.view(path)` lets the model look at an image itself, for example a screenshot it just took to check a UI change. At most 4 per Run.
- PNG, JPEG, GIF, and WebP up to 5 MB. Images are stored next to the session and logged by reference; resume brings them back. Models without image input say so before sending.

## Sandbox

- Commands the model runs can write only inside the project, temporary directories, and common build caches. Reads and network are unchanged.
- Linux uses Landlock (kernel 5.19+), macOS uses `sandbox-exec`; nothing to install. Edits and writes outside the project are refused the same way.
- `[sandbox] writable = [...]` adds directories; `[sandbox] mode = "off"` or `NIB_SANDBOX=off` turns it off. `/status` shows the state.

## Editing

- `@` completes project paths in the input, respecting `.gitignore`. The message carries the path; nothing is inlined.
- Click a Run's title to open just that Run. Ctrl+O opens the latest one.
- Slash commands typed during a Turn stay in the editor with `Turn running · retry command when it ends`, instead of disappearing.
