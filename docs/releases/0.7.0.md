# nib 0.7.0

Smoother, quieter, and steadier. Answers now flow instead of arriving in lumps, long answers no longer slow the interface, and coming back after a break no longer starts with an error.

## Streaming

- Text that arrives in bursts is released over the next few frames (at most 40 ms behind arrival), on grapheme boundaries. The first fragment still appears immediately; Turn end, cancel, retry, and Run start show everything at once. Session logs are never delayed.
- Completed Markdown lines cache their layout, so long answers stay responsive: at 30k characters, frame time p95 dropped from 16.7 ms to 0.5 ms and key latency during streaming from 181 ms to 20 ms.
- Frames are paced from frame start, so the 16 ms interval no longer stretches by the render time.

## Status that matches the screen

- `Thinking` while the model streams reasoning; `Generating response` only once visible text arrives; `Writing Run` unchanged.
- The activity line is dim during normal work and turns yellow only for retries or 30 s without progress.
- Scrolled up while output continues: `New output below · PgDn to return`. The hint survives narrow terminals.
- A retried attempt leaves one dim `Interrupted · retrying` line instead of disappearing silently.

## Codex WebSocket

- Before reusing the connection, nib checks whether the server already closed it and reconnects directly. Returning after an idle break (the server closes idle sockets after roughly 75–82 s) no longer shows `Retrying` or waits a 1 s backoff. Healthy idle connections keep incremental reuse.

## Project

- All documentation is in English; `README.zh-CN.md` remains the Chinese entry.
- CI runs unit tests on Linux and macOS and the end-to-end suite in parallel on every push (about 4 minutes). Release builds compile the four targets in parallel.
