# nib 0.3.0

This release focuses on reproducible Runs and reliable concurrency for tools and tasks. nib becomes open source under the MIT license.

## Breaking changes

- **`tools.agent` failures no longer reject**: success returns `{ ok: true, id, text, usage, changes }`; timeout, crash, or nonzero exit returns `{ ok: false, id, error, text, usage, changes }`. Only argument errors and user cancellation (Esc) still reject.
- **One failed call within a Run no longer cancels other calls**: after top-level Promise rejection, in-flight and queued tools finish; the Run reports the original rejection. Only user cancellation or JS timeout stops them, adding `[stopped before completion: …]` to output.
- **Turns no longer have a default Step limit**: previously fixed at 50. Set `max_steps` in `config.toml`'s `[limits]` when needed; system then states the limit, and Run output includes remaining Steps when no more than 3 remain.
- **Bash cleans up its entire process group on exit**: processes started with `nohup` or `&` terminate when the command returns. Use `tools.bash({ background: true, detached: true })` for long-running services.
- **`write` rejects stale overwrites**: external changes since this Session's last read cause rejection; `read` again before writing.

## New features

- **Tool recording and offline replay**: arguments/results record by default to `~/.nib/sessions/<id>.calls.jsonl` (mode 0600). `nib replay <id> --run 1:0` or `--all` reruns Run JS against recorded results without model requests, compares output byte for byte, and reports the first divergence; `--script` reruns revised code. Set `NIB_RECORD=off` to disable recording. See [replay.md](../replay.md).
- **Background tasks**:
  - `tools.agent` and `tools.bash` accept `background: true`, immediately returning a task id; results arrive as messages in later Steps;
  - Bash with `detached: true` survives across Turns without blocking final answers, suitable for development servers;
  - `tools.stop({ id, reason })` stops tasks by id; reason must be nonblank, and cancellation reminds the model that unfinished validation has no passing result.
- **Subagent reuse**: `tools.agent({ resume: "a1", prompt })` continues the original child Session's history with the same task id.
- **Subagents accept individual `model` and `effort` settings**, returning changed files in `changes`.
- **Unified task numbering**: agents use `a1, a2…`, bash uses `b1, b2…`, increasing throughout the Session and continuing after resume. TUI status trees show subtasks below Runs; foreground bash also appears after 3 seconds.
- **`tools.sleep(ms)`**: cancelable waits for polling within Runs.
- **Per-Step main-model reasoning effort**: the model can request lower effort for the next Step. The user's setting is the ceiling, restored automatically after Run failure or user interjection.
- **TUI**:
  - Interject during a Turn; messages queue for subsequent delivery;
  - Each Turn ends with a usage summary: reasoning/tool time, tokens, cache hits, tool data, and bytes entering context (`tool bytes→output bytes B`).
- **New `[limits]` in `config.toml`**: configure `tools.llm` and subagent concurrency/quotas, `max_steps`, and `stream_idle_timeout_s`. See [config.md](../config.md#limits).
- **Experiment tags and grouped statistics**: logs record system-prompt version and enabled patches; `scripts/stats.py --group-by` compares round trips and time by these dimensions. `NIB_PATCHES_OFF` disables specified prompt patches.

## Improvements and fixes

- File safety:
  - `edit` and `write` use same-directory temporary files and atomic rename;
  - nib processes coordinate reads/writes to the same file through `~/.nib/locks/`, including child Sessions.
- Model streams without data for over 300 seconds (configurable) are treated as disconnected and retried rather than hanging indefinitely.
- `tools.bash` no longer waits for background children inheriting stdout to exit.
- Internal background-task errors report once; result bytes count toward the receiving Step.
- Run change statistics accumulate per edit/write, excluding concurrent changes from other processes.
- Completed Run tool summaries in the TUI count actual calls.
- Heredoc bodies no longer consume the bash safety check's word budget.
- `tools.grep` accepts RegExp literals.
- Internal refactoring splits `session`, `sandbox`, `tui`, and `transcript` into small modules by responsibility without behavior changes.
