# nib 0.6.0

nib now connects beyond Codex: built-in Claude, OpenAI, DeepSeek, and Grok, plus custom OpenAI-compatible endpoints, switchable with `/model`. Skills are available but all disabled by default; only enabled skills enter model context.

## `/model`

- One command switches services and models. The list shows only available services: logged-in Codex or those with API keys set. Type to filter, or use `/model anthropic` or `/model anthropic claude-opus-5-5` directly.
- Selections save to `~/.nib/config.toml` for subsequent launches. Switch in place before a Session has conversation; otherwise start a new Session automatically. Old Sessions remain resumable with their original service.

## Provider

- Built-in `codex` (default, behavior unchanged), `openai`, `anthropic`, `deepseek`, and `xai`. Only three wire protocols: Responses, Chat Completions, and Anthropic Messages; adding a service using an existing protocol takes one table row.
- Configure custom endpoints under `[providers.<id>]`: `protocol`, `base_url`, `model`, `context_window`, `api_key_env`. Configuration stores environment variable names, not keys.
- Claude uses prompt-cache breakpoints and signed reasoning continuation; keys reach only nib's own subagents, not model-run bash.
- Legacy `provider = "chat_completions"` configuration and old Session logs still work. See [Providers](https://github.com/yyydddkkk/nib-code/blob/v0.6.0/docs/providers.md).

## Skills

- Supports Agent Skills (`<dir>/<name>/SKILL.md`), scanning `~/.agents/skills`, `~/.nib/skills`, and project `.agents/skills` and `.nib/skills`.
- **All disabled by default.** Inspect with `/skills`, enable with `/skills on <name>`, effective from new Sessions. With none enabled, the system prompt remains byte-for-byte unchanged.
- The model sees only a name, short description, and path, reading full instructions when needed; no new tools. See [Skills](https://github.com/yyydddkkk/nib-code/blob/v0.6.0/docs/skills.md).

## Interface

- Streaming output batches refreshes at about 16 ms for smoother long answers; keys, scrolling, and cancellation still respond immediately; no idle redraws.
- One blank line separates activity and transcript, tightening automatically in small windows.

## Installation and data

- Prebuilt binaries and one-line install: `curl -fsSL https://raw.githubusercontent.com/yyydddkkk/nib-code/main/install.sh | sh`.
- README adds same-model comparisons with Codex CLI and resource measurements; complete data in [benchmarks](https://github.com/yyydddkkk/nib-code/blob/v0.6.0/docs/benchmarks.md).
